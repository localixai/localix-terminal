# Shortcuts and settings

Every command of the window has a key, and every key is yours to change. Settings are one tab, opened with ⌘,.

## Keys

| Keys | Does |
| --- | --- |
| ⌘T, ⌥⌘T, ⇧⌘B, ⇧⌘S | New page, terminal, board, Store. |
| ⌘1…⌘8, ⌘9 | The project's tab by its place, and the last. |
| ⇧⌘], ⇧⌘[ | Next and previous tab. |
| ⌘W, ⇧⌘T | Close the tab (in a tab of several panes, the pane in use), reopen the last closed. |
| ⇧⌘A | Search the tabs. |
| ⌘F, ⌘G, ⇧⌘G | Find in a terminal's output or a page, the next match and the one before. |
| ⌘N | New window. |
| ⇧⌘\ | Split View: the tab beside the next one of its project; in a tab of several panes, the pane in use to a tab of its own. |
| ⌘D, ⇧⌘D | A new terminal right of, or under, the pane in use, in the folder its shell is in. |
| ⌥⌘←→↑↓ | The keys to the pane that way (of two, the one you used last). |
| ⌥⌘], ⌥⌘[ | The next pane, the one before. |
| ⌃⌘←→↑↓ | Move the divider beside the pane in use that way; with ⇧, a longer step. |
| ⌃⌘= | Make the tab's panes even. |
| ⇧⌘↩ | Zoom the pane in use over its tab, the other panes put by and running; again to show them. |
| ⌘O | Open a folder as a project. |
| ⌃⌘P, ⌃⌘W | Switch project, close the project. |
| ⌘L | The address field. |
| ⌘R, ⌘[, ⌘] | Reload, back, forward. |
| ⇧⌘M | The page's size. |
| ⇧⌘C, ⌘↩ | Comment on the page, send. |
| ⇧⌘O | Open the page in your default browser. |
| ⌘Y, ⇧⌘E | History, the Event Center. |
| ⌘, | Settings. |
| ⌘M | Put the window away. |

The panes' keys are the Pane menu's, with Move Pane to New Tab, which has no key until you give it one. A new split, a pane closed, a divider moved or a way to another pane ends a zoom; the next pane and the one before take it along. They are the same over a file as anywhere: ⌘D and ⌥⌘ with an arrow are not the editor's. [Terminals](terminals.md#keys-in-a-terminal) have their own.

## Settings

Theme, how much of the desktop the glass lets through, the interface and code fonts, the terminals' font size, and every shortcut. The window is dark by default; System and Light are in Appearance.

To change a shortcut, click its keys and press new ones. ⌫ takes it off, one already taken asks first, and you can reset one or all.

Settings apply at once and are kept in `~/.config/llxterm/settings.json`.
