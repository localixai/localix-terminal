# Shortcuts and settings

Every command of the window has a key, and every key is yours to change. Settings are one tab, opened with ⌘,.

## Keys

| Keys | Does |
| --- | --- |
| ⌘T, ⌥⌘T, ⇧⌘B, ⇧⌘S | New page, terminal, board, Store. |
| ⌘1…⌘8, ⌘9 | The project's tab by its place, and the last. |
| ⇧⌘], ⇧⌘[ | Next and previous tab. |
| ⌘W, ⇧⌘T | Close the tab, reopen the last closed. |
| ⇧⌘A | Search the tabs. |
| ⌘N | New window. |
| ⇧⌘\ | Split View: the tab beside the next one of its project, or whole again. |
| ⌘O | Open a folder as a project. |
| ⌃⌘P, ⌃⌘W | Switch project, close the project. |
| ⌘L | The address field. |
| ⌘R, ⌘[, ⌘] | Reload, back, forward. |
| ⇧⌘M | The page's size. |
| ⇧⌘C, ⌘↩ | Comment on the page, send. |
| ⇧⌘O | Open the page in your default browser. |
| ⌘Y, ⇧⌘E | History, the Event Center. |
| ⌘, | Settings. |
| ⌘M | Put the window away. |

[Terminals](terminals.md#keys-in-a-terminal) have their own.

## Settings

Theme, how much of the desktop the glass lets through, the interface and code fonts, the terminals' font size, and every shortcut. The window is dark by default; System and Light are in Appearance.

To change a shortcut, click its keys and press new ones. ⌫ takes it off, one already taken asks first, and you can reset one or all.

Settings apply at once and are kept in `~/.config/llx-desk/settings.json`.
